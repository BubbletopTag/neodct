# NeoDCT OS Changelog

0.3.9a
Added
- The phone sets its own clock. It starts from the date the software was
  built and corrects itself over the internet once there is a signal.
- Predictive typing. Press # until a pencil appears next to "abc", then
  press each letter's key once and the phone guesses the word. Press * for
  the next word the same keys could spell, and clear to take one key back.
  The guess is underlined until you type a space, so you can see what is
  still a guess. It knows 315,000 words, "NeoDCT" among them.

Fixed
- Websites no longer report security warnings. The phone believed it was
  1970, and no certificate on the internet is valid that far back.
- Update can find updates again. "Look online" reported that nothing was
  published no matter what had been released, because the phone asked for
  the newest finished release and every NeoDCT release is marked as a
  test build. This is the first version that can see them; older ones
  cannot, so this one has to be installed from a card.

0.3.8a
Added
- Downgrade, in the engineering tools: lists every published release and
  installs the one you pick, so you can go back to an older version when a
  newer one gives you trouble.

0.3.7a
Added
- The phone can update itself over the internet. Update now offers to look
  online when there is nothing on the card, downloads the release built for
  this phone, and installs it the same way a card update is installed.
- The browser reports itself in purple, and says what it is doing: the
  pages it opens, how much memory and processor it is using together, and
  any security warnings about a site, in red.

Changed
- The startup picture now appears at the end of start-up, after the system
  messages, rather than before them.

0.3.6a
Added
- The serial log opens with the NeoDCT name and version, and every service
  now has its own colour. The modem is blue, the system green, anything
  that failed is red.
- The modem talks to the serial console as it works. It used to keep
  everything it knew in a file on the phone.

Fixed
- Mobile data. Each dial attempt was taking a connection slot from the
  modem and never giving it back, so after enough tries the modem stopped
  answering until it was power-cycled.

0.3.5a
Changed
- The phone now tries the modem's QMI data path first. It used to work
  through every APN on the older path before reaching the one that
  connects, which cost minutes on each start-up.

0.3.4a
Fixed
- Mobile data now connects. The QMI dial dropped the carrier's session the
  moment it finished setting it up, and only ever offered one APN.
- The phone no longer waits fifteen seconds at every boot for an ethernet
  port it does not have.

0.3.3a
Added
- Boot logo on the phone's own screen, drawn from the initramfs before the
  system is mounted.
- Recovery is visible on hardware: the panel comes up with a sad face when
  the phone drops into recovery or panics, instead of showing nothing.
- Recovery can be driven over the serial console.
- Luckfox Pico Mini B: the user partition can be ubifs on raw NAND, not
  only ext4 on a block device.

0.3.2a
Added
- Power app: switch off, restart, or restart into recovery.
- The browser takes the keypad: 2/4/6/8 move the cursor, 5 follows a link,
  and # reaches text entry for a web address.

Changed
- "MusicPlayer" is now "Music" and "System Update" is now "Update".
- New Browser and Update icons, drawn to match the rest of the set.

Removed
- Call forwarding, which was never implemented.

0.3.1a
Added
- Software update page: the release picture, version, size, build date and
  whether it is signed, with the notes scrolling underneath.
- Updates can carry a 64x64 picture, covered by the same signature.

Changed
- Installing is two presses: Install, then Restart.
- Contacts and messages are backed up to the card automatically.
- One progress bar for the whole install, with the reading under it.
- Unsigned builds warn once, then ask again in engineering mode only.

Fixed
- The build wrote a machine path into the platform field, so an update built
  anywhere else was refused as the wrong hardware.
- The boot splash showed a version typed in by hand.

0.1.5a
Added
- The Changelog - ... ... This wasn't a thing before. So the previous versions aren't really tracked.
- Linux Shell App - Full Linux root shell that can run on top of the GUI
- EXPERIMENTAL WALLPAPER ENGINE - Extremely basic implementation of a wallpaper engine that loads and dims 240x240 jpeg images.
- Music Player Application

Changed
- libjpeg from "jpeg-turbo" to just "jpeg"
- "Snake" to "Games" (Updated manifest)
- Replaced the extremely basic Web Browser application that was based on netsurf-fb with a full custom browser based on webkitgtk that runs inside of cage. (Very proud of this one)
- Replaced many placeholder icons with real icons! :)
